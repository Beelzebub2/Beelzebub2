## ⚡ About me

I like turning repetitive, awkward, or overly manual workflows into software that just handles them.

- 🔭 Building **desktop apps, automation tools, and open-source utilities**.
- 🐧 Interested in **Windows/Linux compatibility**, application tooling, and making technical workflows easier to use.
- 🧰 Most often working with **Python, TypeScript, PowerShell, C++, Qt, Electron, and React**.
- 🧪 I enjoy taking projects from a rough prototype to something people can actually install and use.
